🎬 Netflix Landing Page Clone

A simple Netflix homepage clone built using HTML and CSS.
This project focuses on layout design, styling, and responsiveness inspired by Netflix’s official landing page.

📌 Features

🎥 Netflix-style hero section

🌍 Language selector dropdown

🔐 Sign In button UI

📺 Multiple feature sections (TV, Mobile, Kids, etc.)

📩 Email input for membership

📱 Responsive layout (basic)

🧾 Footer with useful links
